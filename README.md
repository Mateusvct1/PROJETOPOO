# Projeto POO

O presente projeto foi desenvolvido para a disciplina de Programação Orientada a Objetos (POO).

# Barbearia CORTEAGIL

## Objetivo

  O Sistema de Gerenciamento de Barbearia é destinado ao gerenciamento de agendamentos de uma barbearia, automatizando o controle de atendimentos aos clientes e profissionais.
  
## Funcionalidades
  
* Cadastro de clientes, barbeiros, gerentes;
* Agendamento de horários;
* Controle de serviços;
* Gerenciamento de barbeiros;
* Histórico de atendimentos;
* Sistema de login;
* Cancelamento de agendamentos
    
## Tecnologias usadas

* Java (linguagem);
* Programação Orientada a Objetos (POO);
* Git e GitHub
